# 🏆 볼알 2026년 북중미 월드컵 쏜다 쏜다 쏜다 웹 앱 (Notion Style & Mobile-First)

6명의 친구들과 함께 카카오톡으로 공유하며 2026 북중미 월드컵 32강 진출팀을 예측하고 맞추는 웹 애플리케이션입니다. Notion 스타일의 깔끔한 화이트 테마 디자인과 모바일 최적화 레이아웃으로 제작되었습니다.

## 🌟 주요 기능

1. **Notion 감성의 화이트 디자인**: 
   - 깔끔한 하얀색 배경, 소프트한 회색 테두리, 그리고 직관적인 이모지를 적극적으로 활용하여 Notion 페이지의 느낌을 구현했습니다.
2. **모바일 최적화 (Mobile-First)**:
   - 카카오톡 인-앱 브라우저 및 스마트폰 터치 조작에 완벽히 대응할 수 있도록 48px 이상의 터치 영역, 가로 스크롤 테이블, 그리고 하단 고정 액션바를 제공합니다.
3. **참여자 선택 및 32개 팀 예측 제약**:
   - 기본 등록된 7인(**정성호, 정누리, 김제식, 홍형권, 박태홍, 최성원, 송경수**)의 이름을 선택하거나 새 인물을 직접 추가할 수 있습니다.
   - 각 조당 **2~3개의 진출팀**을 선택할 수 있으며, **전체 선택된 국가의 합계가 정확히 32개**가 되어야 예측 작성이 완료되고 링크를 공유할 수 있습니다. (8개 조는 3팀, 4개 조는 2팀을 선택해야 합계 32개가 맞춰집니다.)
4. **그룹 자동 동기화 공유 링크 (Auto-Merging Group Share)**:
   - **DB나 서버 없이도 실시간처럼 데이터가 동기화**되는 스마트 머지 시스템입니다.
   - 내가 링크를 공유할 때, **현재까지 내 폰에 저장된 모든 친구들의 예측 데이터**가 URL에 함께 압축되어 포함됩니다.
   - 단톡방에서 다른 친구가 내 링크를 누르면, 그 친구의 브라우저에 여태까지 쌓인 모든 친구들의 데이터가 즉시 합쳐져서 저장됩니다.
   - 친구들이 카톡방에서 서로 링크를 주고받는 과정에서 자연스럽게 모든 참여자의 데이터가 자동으로 동기화됩니다.
5. **비교 대시보드 (Consensus Board)**:
   - 다른 친구들의 선택지를 한 테이블에서 모아보고, 그룹 내에서 어떤 국가가 가장 인기가 많은지 통계를 확인합니다.
6. **실시간 순위 산정 (Leaderboard)**:
   - 32강 진출이 확정될 때마다 관리자가 실제 진출 국가를 체크하면, 각 참여자들의 점수(1개 매칭 시 1점)와 실시간 등수가 자동으로 갱신됩니다.

## 🚀 실행 및 테스트 방법

### 1. 로컬에서 열기
단순히 브라우저에서 [index.html](file:///c:/world/index.html) 파일을 직접 더블 클릭하여 열어서 사용할 수 있습니다.

또는 로컬 서버를 띄워 테스트하려면 터미널에서 아래 중 하나를 실행하세요:

**Python 사용 시:**
```bash
python -m http.server 8000
```
브라우저에서 `http://localhost:8000`으로 접속합니다.

**Node.js/npm 사용 시:**
```bash
npx http-server
```

### 2. 카카오톡 공유 및 자동 동기화 시나리오
1. **정성호**가 사이트에 들어와 **"정성호"** 태그를 누릅니다.
2. A조부터 L조까지 조별로 2~3개씩 진출팀을 탭하며 **총 32개 팀**을 정확히 골라 완료합니다. (완료 시 배지가 녹색 `🎉 완료` 로 변경됨).
3. 화면 하단의 **"링크 공유"** 버튼을 눌러 단톡방에 공유합니다.
4. **정누리**가 단톡방에서 이 링크를 누르면 **정성호**의 데이터가 정누리 브라우저에 저장되고, 정누리도 자기 예측을 입력한 후 다시 링크를 공유합니다. (이때 공유된 링크에는 **정성호 + 정누리**의 데이터가 모두 들어있습니다.)
5. **김제식**이 정누리가 보낸 링크를 누르면, **정성호 + 정누리**의 예측 데이터가 김제식 브라우저로 한꺼번에 저장됩니다.
6. 이렇게 몇 번 링크를 주고받으면 단톡방 구성원 전원의 데이터가 서버 없이도 모두의 폰에 완벽히 동기화됩니다.
